# 集智芬享 · 复利计算器（分享版）

可分发的复利计算器单页应用，Claude UI 风格。功能上和主版本完全一致，唯一区别：

**货币换算 API Key 由用户自己配置，不再硬编码。**

## 部署

直接把这个目录里的三个核心文件传到任意静态托管：

```
index.html
styles.css
script.js
```

可选放上 `README.md`。无构建步骤、无依赖。

GitHub Pages、Vercel、Netlify、Cloudflare Pages、自己的 Nginx 都行。

## 用户使用流程

1. 打开页面，可以直接使用基础复利计算（无需 API Key）
2. 想要切换货币时，点击右上角齿轮图标
3. 按提示去 [exchangerate-api.com](https://www.exchangerate-api.com/) 注册一个免费账号
4. 复制自己的 API Key，粘贴到弹窗中点"保存并校验"
5. 通过校验后，所有货币之间可以自由切换换算

## API Key 存储说明

- 仅保存在用户浏览器的 `localStorage` 中（key: `fx_api_key_v1`）
- 不会发送到任何第三方服务器
- 切换浏览器或清除站点数据后需要重新输入

## 配额

ExchangeRate-API 免费档每月 1500 次请求；本工具会缓存当前会话的汇率 1 小时，
单个用户日常使用基本不会触及上限。

## 功能

- 复利正向计算：本金 / 追加 / 利率 / 时长 / 追加方式
- 利率和时长支持 年/月/天 三种单位（利率周期 = 复利频率）
- 多货币切换（10 种主流货币，按需扩展 `CURRENCIES` 数组）
- 增长曲线图 + 逐期明细表
- 一键导出整页结果为 PNG
- 目标利率反推：输入本金 + 期望金额 + 时长 → 反算所需利率
